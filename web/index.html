      バックアップ

      プリセットはこのブラウザにだけ保存されます。JSON で書き出し / 読み込みでき、Chrome 拡張の Smart Keysmith とも同じ形式です。読み込むと今のプリセットはすべて置き換わります。

      仕組み
      • 生成はこのブラウザの中だけで行います。乱数は crypto.getRandomValues を棄却法で偏りなく使っています(generator.js の rand() / generate())
      • 生成したパスワードは保存も送信もしません。Local Storage に残すのはプリセットの設定だけです
      • ページの設定 (Content-Security-Policy の connect-src 'none') で通信そのものを禁じています。開発者ツールの Network で通信が起きていないことを確かめられます
      • Chrome 拡張版とソースコード: GitHub
